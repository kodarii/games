- Degraded state (`candidatesQuery.data?.degraded === true` OR `candidatesQuery.isError`): silently treat as empty matches (the user can still type and submit manually). No error toast — the existing modal pattern is to render errors only on mutation failure.
- Footer of dropdown: light-grey strip with `↑↓ navigate · ↵ select · N matches` (kbd-style spans).
