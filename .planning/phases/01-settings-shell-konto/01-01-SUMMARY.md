## Deviations from Plan

### 1. [Rule 3 - Blocking issue] shadcn CLI alias path resolution

- **Found during:** Task 1 (a) — `bunx shadcn@latest add alert-dialog card label`
- **Issue:** The CLI wrote four files into a literal `apps/client/@/components/ui/` directory instead of resolving the `@/components/ui` alias to `apps/client/src/components/ui/`. It also created a `button.tsx` clone there (would have clobbered our custom variants if accepted).
- **Fix:** Moved the three new primitives (`alert-dialog.tsx`, `card.tsx`, `label.tsx`) into the canonical `apps/client/src/components/ui/` location via `mv`. Deleted the stray `apps/client/@/` directory entirely. The orphaned `button.tsx` clone in `@/` was discarded — original `button.tsx` was untouched and our `destructive` variant was layered onto it.
- **Files modified:** filesystem move, no diff-able edit beyond accepting the three generated files at correct path.
- **Commit:** `4ec1f11`

### 2. [Rule 3 - Blocking issue] Biome line-width 100 forced single-line import in settings-nav.tsx

- **Found during:** Task 3 lint pass
- **Issue:** Initial multi-line import block `import { Tooltip, TooltipContent, TooltipProvider, TooltipTrigger } from '@/components/ui/tooltip';` was written as 5-line, but Biome's formatter reformatted to single-line (fits in 100 chars).
- **Fix:** Manually collapsed to single line.
- **Files modified:** `apps/client/src/pages/settings/settings-nav.tsx`
- **Commit:** `6208991` (folded into Task 3 commit)
