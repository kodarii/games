<objective>
Wyciągnąć migracje DB z boot-path API do versioned `scripts/deploy.sh` wykonywanego ahead-of-restart na VPS. `client.ts` zachowuje auto-migrate tylko dla dev (`NODE_ENV !== 'production'`).

Purpose: Eliminuje boot-time race (proces nie wstaje dopóki migracja w toku); `set -euo pipefail` zapewnia, że bad migracja zatrzymuje deploy PRZED restartem → stary proces zostaje przy życiu na starym kodzie + starej migracji. Zero rollback magic, zero auto-revert, zero "boot z brakami".

Output: `scripts/deploy.sh` (nowy, +x), 1-linijkowa zmiana w `client.ts`, update w CONCERNS.md.
</objective>
