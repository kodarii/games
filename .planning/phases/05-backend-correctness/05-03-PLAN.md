<objective>
Zlikwidować N+1 SELECTów w `applyMerge` (`drizzle-import-repository.ts`). Zamiast per-row SELECT, wykonujemy DWA batched SELECTy z `inArray(externalId, [...])` na początku transakcji i lookup'ujemy w pamięci.

Purpose: Plan importu z 100+ wierszami robi obecnie 100+ roundtripów do SQLite wewnątrz transakcji — to dziesiątki ms latency, błąd kategorii "N+1 reads in a tight loop". Po fixie: 2 SELECTy stała, reszta to in-memory lookup + per-row INSERT/UPDATE (UPDATE per-row zachowane świadomie — D-13).

Output: Refaktoryzowany `applyMerge` (dwa batched reads + Map'y); semantyczny test pinujący regresję (100 games + 5 platforms + per-user isolation + empty-array edge case); CONCERNS update.

**Depends on plan 05-02 (toGameInsertRow already wired into INSERT branches).**

**Q7 (test harness — in-memory + DI):** Pierwsza wersja planu zakładała test na shared dev.db z `crypto.randomUUID()` jako USER_A/B + `afterAll DELETE WHERE userId LIKE 'test-merge-%'`. Trzy realne problemy:
  1. **Garbage rośnie monotonicznie** — `randomUUID()` to anty-cleanup: każdy crashed run zostawia ślad, którego kolejne runy nie znajdują. Na Mikrusie 1GB to konkretny koszt: backup snapshot (plan 05-01) rośnie liniowo ze śmieciem.
  2. **WAL contention z dev API** — `bun --hot` może trzymać długo-żyjącą read transakcję; test piszący 100+ rows triggeruje `SQLITE_BUSY`. Flaky integration tests uczą zespół ignorować czerwone CI.
  3. **Test 2 (per-user isolation) semantycznie skażony** — cel: "merge dla A nie dotyka B". Robisz to na bazie gdzie żyją inni "B-podobni" (developer data, śmieci z poprzednich runów). Test może przejść bez testować invariant.
Rozwiązanie: in-memory SQLite + small DI refactor `DrizzleImportRepository` (optional constructor arg, default = singleton — production wiring bez zmian). Statyczne TEST_USER_A/B (izolacja eliminuje przyczynę dla losowości). Pattern zgodny z 05-02 Task 3 — Phase 5 utrwala in-memory jako standard dla nowych integration testów. Decyzje D-30..D-32 do dodania w 05-CONTEXT.md przez plan 05-07 sweep.
