Plan's claim "Round-trip invariant pin: if any future change... silently drops a column on either direction, this test fails" is FALSE for 4 of the 5 fields.
**Recommendation:** Narrow the round-trip test scope honestly:

  - Coverage for the 2 fields NOT in snapshot (coverImage + 3 metadata cols, treated as a block) is then carried fully by apply-merge.test.ts Test 5/6 — which already does direct row inspection.
**Impact:** RECOMMEND-CHANGE (the test as written passes vacuously for half the bug surface — false confidence is worse than a smaller honest test).
